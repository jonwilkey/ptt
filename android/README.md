# android/

The family push-to-talk Android app (Kotlin, Gradle), distributed as a signed, sideloaded APK.

Filled in starting with milestone 2 (enrollment and paging core); the widget, live talk, and
clip fallback follow in milestones 3–5. `version.txt` holds the app version that release-please
bumps (tags `android-vX.Y.Z`).
